# ShapeUp 💪 (Active Development)

> **🚧 Note:** This project is currently in active development. Features and UI are continuously being updated and refined.

ShapeUp is a comprehensive, full-stack health and fitness tracking application designed to provide users with a centralized platform for managing their workouts, daily nutrition, and overall wellness goals. 

## 🚀 Tech Stack
This project is built using the **MERN** stack:
* **Frontend:** React.js, Redux Toolkit, CSS
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Other Tools:** AI integrations for personalized support, automated email reminders.

## ✨ Features (Current & Planned)
* **Custom Workout Tracking:** Log routines, specific exercises, and track progress.
* **Nutrition & Macro Management:** Daily meal planning and a built-in calorie calculator.
* **Daily Metric Logging:** Keep track of water intake, daily steps, and active calories burned.
* **AI Support Chatbot:** An intelligent assistant to help users with fitness and diet queries.
* **Automated Reminders:** Notification system to help users stay consistent.

## 🛠️ Installation & Setup (Local Development)

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone [https://github.com/yourusername/shape-up-app.git](https://github.com/yourusername/shape-up-app.git)
2. Install Backend Dependencies:
Bash
cd backend
npm install

3. Install Frontend Dependencies:
Bash
cd ../frontend
npm install

4. Environment Variables:
Create a .env file in the backend directory.

Add your MongoDB URI, JWT Secret, and any required API keys.

5. Run the Application:
You can start the backend and frontend servers using npm start in their respective directories.
